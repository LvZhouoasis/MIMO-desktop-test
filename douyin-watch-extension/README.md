# 抖音关注监控（浏览器扩展）

监控你关注的抖音博主：**一有新视频，立刻推送到你的微信**。

- 不需要安装 Python
- 不需要自己的服务器
- 不需要懂代码
- 所有数据只保存在你自己的浏览器里

---

## 它能做什么

1. 你添加若干抖音博主（或一键导入关注列表）
2. 浏览器每隔几分钟自动打开他们的主页看一眼
3. 发现新视频后，通过 **Server酱** 发到你的微信
4. 每天晚上 20:00 左右还会发一条简单摘要

> **重要前提**：检测依赖 Chrome 在运行。关掉浏览器后无法监控（这是浏览器扩展的天然限制）。

---

## 适合谁

- 想第一时间知道关注的博主更新
- 不想一直刷抖音，希望微信提醒「谁发了新视频」
- 能接受：电脑开着 Chrome 时才监控

## 安装前准备（只需要 2 样东西）

| 准备项 | 说明 |
|--------|------|
| **Chrome 或 Edge 浏览器** | 电脑版，能装扩展 |
| **微信 + 一个推送 Key** | 用「方糖」服务号，免费 |

### 如何获取微信推送 Key（详细）

1. 手机微信搜索并关注服务号：**方糖**  
2. 电脑打开网址：<https://sct.ftqq.com/>  
3. 用微信扫码登录  
4. 页面上会显示你的 **SendKey**，样子类似：`SCTxxxxxxxxxx`  
5. 复制这串 Key，等会儿粘贴到扩展里  

如果你用的是安卓手机：微信里就能收到通知，一般不用额外装 App。

## 安装步骤（小白版）

### 第 1 步：下载本项目

任选一种：

**方式 A（推荐）**  
到 GitHub 本页面右上角点 **Code → Download ZIP**，下载后解压。

**方式 B**  
如果你会用 git：

```bash
git clone https://github.com/LvZhouoasis/MIMO-desktop-test.git
```

然后进入目录：`MIMO-desktop-test/douyin-watch-extension`

### 第 2 步：打开浏览器的「扩展管理页」

在 Chrome 地址栏输入并回车：

```text
chrome://extensions
```

Edge 则是：

```text
edge://extensions
```

### 第 3 步：打开「开发者模式」

在扩展管理页 **右上角**，打开开关：**开发者模式**（Developer mode）。

### 第 4 步：加载扩展

1. 点左上角 **「加载已解压的扩展程序」**（Load unpacked）
2. 选择你解压出来的 **`douyin-watch-extension` 文件夹**  
   （注意：要选到能看到 `manifest.json` 的那一层文件夹）
3. 确认列表里出现「抖音关注监控」

### 第 5 步：固定到工具栏（方便以后点）

点浏览器右上角的 **拼图图标**，找到「抖音关注监控」，点旁边的 **图钉** 固定。

### 第 6 步：完成首次配置

1. 点击工具栏上的「抖音关注监控」图标  
2. 会看到 3 步引导页  
3. 点击「打开 sct.ftqq.com 获取 Key」，粘贴你的 Key  
4. 点 **「发送测试通知到微信」**  
5. 手机微信「方糖」里应出现测试消息  
6. 点 **「完成，开始使用」**

到这里，安装配置就全部结束了。

## 怎么添加要监控的博主

### 方法一：添加单个博主（最稳，推荐先用这个）

1. 用 Chrome 打开抖音网页版：<https://www.douyin.com/>  
2. **登录你的抖音账号**（必须登录，否则可能看不到完整主页）  
3. 打开某个博主的主页，网址应类似：  
   `https://www.douyin.com/user/MS4wLjABAAAA...`  
4. 点扩展图标 → **「+ 当前页博主」**  
5. 列表里出现该博主即成功  

也可以在抖音页面上 **右键 → 「监控这个抖音博主」**。

### 方法二：导入关注列表（一次加很多）

1. 打开抖音，并进入自己的 **「关注」列表** 页面  
2. 先往下滚动几次，让列表加载出来  
3. 点扩展 → **「导入关注」**  

> 导入依赖页面结构，如果失败请改用方法一逐个添加。

### 首次添加说明（为什么没有立刻推送）

第一次添加某个博主时，扩展会把当前已有的视频记成「基线」，**不会**把历史视频当成新视频轰炸你。  
从下一次轮询开始，只有真正新发的视频才会推送到微信。

## 日常怎么用

| 操作 | 怎么做 |
|------|--------|
| 开始自动监控 | 保持 Chrome 打开；扩展右上角「自动」保持开启 |
| 看有没有漏 | 点扩展 →「立即检查」 |
| 临时停某个人 | 列表里点「暂停」 |
| 不想要了 | 列表里点「删除」 |
| 改轮询频率 | 设置里改「轮询间隔」，建议 2 分钟 |
| 半夜不被打扰 | 设置里改「静默开始 / 结束」，例如 23:00–08:00 |

手机上：只要微信「方糖」能收到服务号消息即可，点通知里的链接可跳转视频。

## 常见问题（FAQ）

### 1. 测试推送失败怎么办？

- Key 是否以 `SCT` 开头，有没有复制全  
- 微信是否关注了「方糖」  
- 登录 <https://sct.ftqq.com/> 看额度是否用完  
- 网络是否能访问外网（扩展需要请求 `sctapi.ftqq.com`）

### 2. 一直收不到博主更新？

依次检查：

1. Chrome 是否一直开着（关了就不会检测）  
2. 扩展右上角「自动」是否打开  
3. 该博主是否被「暂停」  
4. 是否已登录抖音  
5. 点「立即检查」，看是否提示解析失败  

### 3. 提示解析失败 / 解析结果为空？

多半是抖音网页改版了。可以：

1. 确认已登录抖音  
2. 手动打开该博主主页，等页面完全加载后再「立即检查」  
3. 若长期失败，需要改代码里的解析规则：  
   `src/content/parser.js`（开源项目，欢迎提 Issue / PR）

### 4. 会不会偷我的抖音账号密码？

不会。扩展：

- 不读取、不保存你的密码  
- 使用你浏览器里已登录的状态读取你可见的主页信息  
- 只把「博主昵称 + 新视频标题/链接」发到 **你自己填写的** Server酱  
- 没有任何作者服务器，数据不出你的电脑（除了发往 Server酱）

### 5. 可以监控直播吗？

当前版本只监控 **视频更新**，不包含直播开播提醒。

### 6. 手机浏览器能装吗？

不能。这是 Chrome/Edge 桌面扩展，需要电脑浏览器。

### 7. 能不能不关电脑也监控？

不能。检测必须由打开着的浏览器完成。若需要 24 小时监控，需要另做服务器方案（本仓库不提供）。

├── manifest.json              # 扩展清单
