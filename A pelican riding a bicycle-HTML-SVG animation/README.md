# A pelican riding a bicycle — HTML / SVG animation

用纯前端（单个 `index.html`）绘制的卡通**鹈鹕骑自行车**动画：SVG 画角色与场景，CSS 驱动骑行与滚动，JS 负责随机切换场景、季节、姿态，并触发下车互动。

线上预览（CodeSandbox 静态托管，与本目录同源）：  
https://fl69pg.csb.app

---

## 项目特点

- **零依赖**：无构建、无 npm 包、无外部 CDN；双击 HTML 即可运行
- **单文件交付**：HTML + CSS + JS 全部内联在 `index.html`，方便拷贝与分享
- **纯矢量**：角色、自行车、建筑、树木、铁轨等均为 SVG，可无损缩放
- **多姿态骑行**：悠闲骑 / 快骑冲刺 / 杂耍（抛球+扇翅）/ 翘头特技 / 脱手闲骑，随机切换
- **多场景**：城市马路、郊外小路、铁路旁；背景按 400px 单元双份平铺，滚动无缝
- **四季随机**：春（花开）/ 夏（浓绿）/ 秋（落叶）/ 冬（积雪+飘雪），不按固定顺序循环
- **肢体同步**：脚固定在脚踏上随曲柄转，大腿绕髋摆动，周期与轮子/车道线共用同一 CSS 变量
- **下车互动**：骑行约 14–22 秒后随机下车；环境、车、身体全部静止，仅保留道具与角色的互动小动作
- **无障碍**：系统开启「减弱动态效果」时自动停动画

## 如何运行

### 方式一：直接打开（推荐）

1. 找到本目录下的 `index.html`
2. 用 Chrome / Edge / Firefox **双击打开**
3. 动画自动循环播放，无需刷新

### 方式二：本地静态服务（可选）

若浏览器对 `file://` 有限制，可在本目录执行：

```bash
# 任选其一
npx --yes serve .
python -m http.server 8080
```

然后访问提示的本地地址。

### 方式三：在线

打开 https://fl69pg.csb.app （内容为本目录 `index.html` 的部署副本）

## 功能时间线（大致）

| 事件 | 间隔 |
|------|------|
| 骑姿切换 | 约 5.5–8 秒 |
| 场景切换（淡入淡出） | 约 16–22 秒 |
| 季节切换 | 约 20–28 秒 |
| 下车互动 | 骑行约 14–22 秒后触发，互动约 5–7 秒后上车 |

互动内容随场景变化：

- **城市**：按过街按钮
- **郊外**：闻路边花丛
- **铁路**：查看信号灯

页面上方状态栏会显示：场景 / 季节 / 姿态 / 状态。

## 技术要点

- **周期同步**：轮子、曲柄、腿脚、车道线共用 CSS 变量 `--pedal-dur`，避免各转各的
- **无缝滚动**：建筑、路灯、树、栅栏、电线杆等按 400px 单元复制两份，`translateX` 循环
- **姿态驱动**：姿态 class 只改 CSS 变量与身体 `transform`，不重画 SVG
- **停车冻结**：`mode-off` 下对背景/车/腿脚 `animation: none`，`action-live` 时才播互动关键帧
- **季节色板**：天空、树叶、路面等颜色由 `.season-*` 上的 CSS 变量控制

## 自定义（改代码即可）

| 想改什么 | 大概位置 |
|----------|----------|
| 切换快慢 | `<script>` 里 `schedulePose` / `scheduleScene` / `scheduleSeason` / `scheduleDismount` 的毫秒数 |
| 颜色/季节 | `<style>` 中 `.season-spring` 等 CSS 变量 |
| 姿态列表 | `poses` 数组与对应 `.pose-*` 样式 |
| 互动文案/道具 | `scenes` 数组的 `interact` 字段，以及 SVG 中 `#prop-city` 等 |
| 画幅 | `<svg viewBox="0 0 800 500">` 与 `.stage` 的 `aspect-ratio` |
