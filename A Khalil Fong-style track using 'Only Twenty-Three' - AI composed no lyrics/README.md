> 中文名参考：方大同《才二十三》气质 · 原创器乐曲 **《草稿箱》**  
> **当前状态：只有曲子（器乐 Demo），没有人声演唱成品。**

---

## 一、这是什么

参考歌手**方大同**《才二十三》的 Neo-Soul / 轻 R&B 抒情路线，用 AI 辅助完成的**原创器乐项目**。

| 项目 | 内容 |

| 风格 | Neo-Soul · 华语 R&B 抒情 · 夜色卧室感 |

## 二、项目特点与功能

### 已完成功能

1. **完整词曲方案**（未演唱，仅文字 + 谱）  
   - 中心意象：邮箱「草稿箱」——未寄出的话、未完成的自己  
   - 主歌 / 预副歌 / 副歌 / 桥段 / 尾声 全结构歌词  

2. **完整器乐编曲**（主交付）  
   - 电钢（Rhodes 风）柱式和弦  
   - 圆润贝斯  
   - 尼龙吉他琶音  
   - Pad 长音垫底  
   - 主旋律动机  
   - 软鼓（Kick / Rim / Hi-hat，带轻微 swing）  
   - 立体声、段落动态（Intro 无鼓 → Verse 轻 → Chorus 满 → Bridge 掉 → 末副歌再推）

3. **Neo-Soul 和声**  
   - 含 `maj9 / m9 / 13 / m7b5 / 7#9 / sus`  
   - Verse 常用：`Abmaj9 – Gm7b5 – C7 – Fm9 – Bbm9 – Eb13`  
   - 副歌：`Abmaj9 – Dbmaj9 – Cm7 – Fm9 – Bbm9 – Eb13 – Abmaj9 – Db6`

4. **可再制作用料**  
   - 跟唱伴奏（无人声旋律）  
   - 导唱版（带主旋律）  
   - 主旋律 MIDI + 歌词对位  
   - ABC 谱  
   - 多套 AI 人声生成提示词（Suno / 海绵音乐等）

5. **可复现渲染脚本**（Python 标准库合成，无第三方依赖）  
   - `render_full.py` — 完整编曲（推荐）  
   - `render_karaoke.py` / `render_demo.py` / `render_midi.py`

### 明确不在本仓库的部分

- **没有人声演唱音频**（未用 Suno/海绵等导出正式人声版）  
- **不包含**方大同原曲音频或采样（仅风格参考）

## 五、当前只有曲子 — 如何做成「完整一首歌（含人声歌词）」

本仓库**只交付器乐**。若要正式人声版，推荐路径如下（按成本从低到高）：

### 路径 1：海绵音乐 / 网易天音（国内，免费额度通常够个人听）

1. 打开海绵音乐 App 或微信小程序，登录  
2. **自定义写歌** → 粘贴 `备选方案_不用Suno.md` 中「统一歌词」  
3. 风格填：  
   `中文流行 R&B 抒情，方大同气质，慢板 72BPM，男声慵懒气声，温暖电钢与木吉他，夜色感，克制深情，不苦情嘶吼，完整歌曲3分半左右`  
4. 生成 → 不够 3 分钟则「续写」或把副歌再贴一遍  
5. **注意**：该路径是**整首重新 AI 生成**，不是在本仓库 WAV 上加人声；听感与本编曲不会完全一致  

详见：`海绵音乐_操作步骤.md`、`备选方案_不用Suno.md`

### 路径 2：Suno（Custom 模式，免费额度有限，登录可能需海外网络）

1. 打开 [suno.com](https://suno.com) → Create → **Custom**  
2. Lyrics 粘贴 `SUNO_正式版.md` 全文（含结构标签）  
3. Style 粘贴文件内 Style 句；Title：`草稿箱`  
4. 时长不足用 **Extend** 接尾声  

详见：`SUNO_正式版.md`、`suno_prompt.txt`

### 路径 3：在本伴奏上录真人声（音质最可控）

1. 耳机播放 **`草稿箱_跟唱伴奏.wav`**  
2. 对着歌词演唱并录音（手机或 Audacity）  
3. 剪映 / DAW 中与伴奏对齐，人声加轻混响后导出  

歌词分段见：`备选方案_不用Suno.md`、`草稿箱_歌词对位.txt`  
详见：`DEMO使用说明.md`

### 路径 4：ACE Studio + 中文声库（AI 歌声对谱演唱）

1. 从官网 [https://www.acestudio.ai](https://www.acestudio.ai) 安装 ACE Studio（青岛时域科技）  
2. 导入 `草稿箱_主旋律.mid`  
3. 粘贴 `草稿箱_歌词对位.txt` 歌词  
4. 导出人声干声 → 与 `草稿箱_跟唱伴奏.wav` 混合  

详见：`ACE_Studio路线.md`  
> 软件可免费下载；云渲染有免费额度，大量导出可能需订阅。

### 路径对比

| 路径 | 是否吃本仓库伴奏 | 费用 | 难度 | 听感 |
|------|------------------|------|------|------|
| 海绵/天音 | 否（整首重生成） | 个人多免费 | 低 | 中文友好，偶有「口水歌」感 |
| Suno | 否 | 免费有限/订阅 | 中（登录） | 整体制作感较好 |
| 真人录 | **是** | 免费 | 看唱功 | 最可控、最「真人」 |
| ACE Studio | MIDI+词，可叠伴奏 | 免费额度+可选订阅 | 中高 | 虚拟人声，可控表情 |

## 七、技术说明

- 渲染：Python 标准库振荡器合成（正弦 + 软包络 + 采样缓存），非真实乐器采样  
- 因此音色偏「电子电钢 / 合成吉他」，适合 Demo 与结构验证；正式发行建议在 DAW 中替换真实音色或走路径 3/4  
- 主旋律曾针对「突兀音、叠层错位」做过声部对位与时值对齐修订（见 `完整编曲说明.md`）
