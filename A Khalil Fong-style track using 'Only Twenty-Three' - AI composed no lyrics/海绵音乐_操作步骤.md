# 海绵音乐操作说明（把《草稿箱》做出来）

先说结论，避免白找入口：

| 我们准备的文件 | 能不能直接丢进海绵音乐 |
|----------------|------------------------|
| 统一歌词（文字） | **能**，粘贴到歌词框 |
| 风格描述（文字） | **能**，填到风格/描述框 |
| `草稿箱_score.abc` 乐谱 | **不能**导入；只给人看旋律走向 |
| `草稿箱_demo.wav` 伴奏 | **一般不能**当底轨加人声（除非 App 有「翻唱/导入伴奏」功能） |

所以：**在 App 里只操作「歌词 + 风格」两样**，其余是参考。

---

## 一、打开与登录

1. 手机应用商店搜「**海绵音乐**」安装  
   （或微信 → 发现 → 小程序 → 搜「海绵音乐」）
2. 打开后用 **抖音账号** 或 **手机号验证码** 登录  
3. 不要找「注册 Suno」那种海外流程，国内登录很快

---

## 二、进入「自定义写歌」

不同版本叫法略有差别，在首页找下面**任一**入口：

- **「自定义写歌」** / **「自定义」** / **「写歌词」**
- 或 **「AI 写歌」→ 选「自定义」**（不要选「灵感一句话」）
- 若只有「灵感创作」：点进去后找 **「高级 / 自定义 / 自己写词」** 切换

目标是能自己贴长歌词，而不是只输入一句灵感。

---

## 三、粘贴歌词（关键）

1. 点进 **歌词输入框**
2. 删掉默认示例词
3. 打开电脑或手机里的文件  
   `caogaoxiang\备选方案_不用Suno.md`  
   复制 **「统一歌词」** 整段（从《草稿箱》到「一直亮着」）
4. 粘贴进去

**段落标记怎么处理：**

- 保留 `【主歌1】【副歌】` 这种中文标记（方便 AI 认结构）  
- 若 App 报错或乱排：把 `【】` 去掉，改成空行分段也可以  
- 不要用 Suno 的 `[Verse]` `[Chorus]` 英文标签（海绵以中文段落更稳）

粘贴后检查：

- 副歌至少出现 **两遍**（我们词里已有）
- 最后一段 **「尾声」要保留**（利于拖到 3 分钟）

---

## 四、填风格 / 情绪

找 **「风格」「曲风」「描述」** 类输入框，粘贴：

```
中文流行 R&B 抒情，方大同气质，慢板 72BPM，男声慵懒气声，温暖电钢与木吉他，夜色感，克制深情，不苦情嘶吼，完整歌曲3分半左右
```

若 App 是 **点选标签** 不是长文本：

| 优先选 | 词 |
|--------|----|
| 曲风 | R&B / 流行 / 抒情 |
| 情绪 | 温暖 / 怀旧 / 治愈 / 夜晚 |
| 人声 | 男声 |
| 速度 | 慢 |
| 乐器 | 钢琴 / 吉他（有则勾） |

标签和文字描述可以并存，以标签为准时把文字描述删掉，避免冲突。

---

## 五、生成

1. 确认 **时长** 选「完整歌曲」或约 **3–4 分钟**（若有该选项）
2. 点 **生成 / 开始创作**
3. 等待 1–3 分钟，通常会出 **1–2 个版本**
4. 点播放听整首，重点听：
   - 是不是男声、够不够「气声」
   - 副歌有没有起来
   - 有没有超过 3 分钟

**免费次数不够时：** 先只生成 1 次，听声线；不行再改风格再生成，不要连点。

---

## 六、时长不够 3 分钟怎么办

1. 生成后看有没有 **「继续写」「加长」「Extend」「续写」**
2. 有：在续写歌词框粘贴（见下），再生成后半
3. 没有：回到歌词框，把 **【副歌】整段再复制一遍** 放在桥段后，重新生成

续写专用词（有续写框时粘贴）：

```
【副歌】
就让草稿箱一直满着
像心口一小块没关灯的夜
等哪天勇气路过
随便点开哪一篇
都能读见我们曾经那么近地犹豫过

【尾声】
草稿箱还亮着
像一句没说完的后来
如果哪天你路过
别清空
就让它一直亮着
```

---

## 七、导出

1. 对满意版本点 **「…」/ 分享 / 导出 / 下载**
2. 免费档常见限制：
   - 只能 App 内听 / 分享到抖音
   - **高清导出** 或批量下载要会员
3. 个人自听：用手机录屏或 App 内收藏即可  
   （要无损文件时再考虑会员，先别充）

---

## 八、和 Demo / ABC 怎么对照

- `草稿箱_demo.wav`：耳机里听 **和声与主旋律动机**，AI 生成的调可能不同，不必强行一样  
- `草稿箱_score.abc`：只给人看「别急着清空草稿箱」那句的音高走向（c–e–f–g–f），**不要找导入按钮**

---

## 九、生成不理想时怎么改（一次只改一处）

| 现象 | 改这里 |
|------|--------|
| 太快、像网络歌 | 风格加「**更慢、68BPM、气声、稀疏编曲**」 |
| 不像方大同、太亮 | 加「**深夜、克制、电钢为主、不要合唱**」 |
| 歌词唱糊 | 删掉部分【主歌4】，句子改短；或整段标成【桥段】 |
| 副歌不记忆点 | 保证两遍【副歌】文字完全一致 |
| 死活不到 3 分钟 | 加长尾声 + 副歌重复；或看是否有续写 |

---

## 十、你现在按这个顺序点

1. 打开海绵音乐（小程序或 App）并登录  
2. 进 **自定义写歌**  
3. 粘贴 **统一歌词**  
4. 粘贴 **风格** 那一句（或勾标签）  
5. 生成 → 听  
6. 短了就 **续写** 或 **副歌再贴一遍**  
7. 满意就收藏/导出
