# Demo 使用说明（跟唱 / 录人声 / 给制作人）

海绵生成不理想时，**以本地 Demo 为正式底轨**。下面是怎么用。

---

## 你现在有 3 个音频

| 文件 | 用途 |
|------|------|
| `草稿箱_跟唱伴奏.wav` | **主用**：无人声旋律，可录自己的唱 |
| `草稿箱_导唱版.wav` | 带主旋律，练音准、对齐歌词 |
| `草稿箱_demo.wav` | 旧版单声道导唱，可忽略 |

约 4 分钟，BPM 72，Ab 大调，立体声（轻鼓点 + 电钢 + 分解吉他 + 贝斯）。

---

## 用法 A：自己唱（手机就能）

1. **耳机**放 `草稿箱_跟唱伴奏.wav`（外放会录进伴奏）
2. 另一部手机 / 录音 App（备忘录、录音机、剪映录音）录人声
3. 对着 `README.md` 或 `备选方案_不用Suno.md` 里的词唱  
   - 忘调时先听 `草稿箱_导唱版` 一小段
4. 用 **剪映**「音频 → 音乐+录音」把人声与伴奏对齐，人声加轻混响

**唱法提示**（贴方大同气质）：主歌轻、贴麦、气声；副歌略开但别吼；句尾留呼吸。

---

## 用法 B：电脑混录（质量更好）

1. 任意 DAW：GarageBand / Reaper / Audacity / Cubase
2. 导入 `草稿箱_跟唱伴奏.wav` 作伴奏轨
3. 建人声轨，戴耳机录（防止串音）
4. 人声：轻压缩 + 短混响（房间感 0.8–1.2s）+ 去齿音
5. 导出 MP3/WAV

Audacity 免费即可：效果 → 混响（GVerb）→ 导出。

---

## 用法 C：给会编曲/翻唱的人

直接把整个文件夹发给对方，并附上：

```
歌名：草稿箱
BPM：72
调：Ab
时长：约 4 分钟
结构：Intro–V1–V2–Pre–Chorus–V3–V4–Pre–Chorus–Bridge–Chorus–Outro
伴奏：草稿箱_跟唱伴奏.wav
词曲说明：README.md
```

对方可在伴奏上重录真吉他/鼓，或只唱人声。

---

## 用法 D：放进「能吃现成伴奏」的 AI 工具

部分国内工具支持 **导入伴奏 / 翻唱 / AI 人声**（入口随版本变）：

- **ACE Studio**（ACE 虚拟歌姬）：可导入 MIDI/伴奏，配中文声库出人声——最接近「按谱唱」
- **音潮 / 部分剪映 AI 歌曲**：有时支持「用我的音频」或翻唱
- **Vocaloid / Synthesizer V** + 中文声库：需要简谱/MIDI，我们 ABC 谱可转

若某 App 有「**导入音频**」「**翻唱**」「**AI 歌声**」，优先导入 `草稿箱_跟唱伴奏.wav`。

**海绵音乐**目前主要是文字生成整歌，**不能**可靠地在你的 WAV 上只加人声——所以别指望它「吃」这个 demo。

---

## 用法 E：只要旋律参考

`草稿箱_score.abc` → 打开 [ABCjs Editor](https://editor.drawthedots.com) 粘贴播放，对照歌词看音高。

---

## 建议你现在的路径

1. 先听一遍 `草稿箱_跟唱伴奏.wav`，确认节奏跟得上  
2. 跟着 `草稿箱_导唱版.wav` 把副歌唱熟（两遍）  
3. 手机或 Audacity 录人声  
4. 剪映合成导出  

若要 **更高配编曲**（真鼓采样、尼龙吉他、更长混响），可以说一下，我可以再出一版加强编曲的伴奏。
