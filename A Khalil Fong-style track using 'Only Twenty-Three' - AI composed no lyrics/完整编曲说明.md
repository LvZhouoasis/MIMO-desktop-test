# 《草稿箱》完整编曲说明

文件：`草稿箱_完整编曲.wav`（约 4′40″ · 立体声 · 72 BPM · Ab）

## 相对旧版改了什么

| 旧问题 | 处理 |
|--------|------|
| 音符突兀 | 主旋律改为级进为主，跳进落在和弦音；去掉强拍上的不协和 |
| 叠层错位 | 各声部统一量化到拍网格；吉他/电钢 attack 微错开 0–5ms，避免「糊成一团」 |
| 单调 | 和声改成 neo-soul 进行（见下）；桥段掉能量；副歌第二遍旋律升高 |
| 过亮/刺耳 | EP 去掉刺耳泛音，加软 tine；Pad 压高频；鼓改软 kick / rim / 轻 hat |
| 声部挤 | 低音只走根音，色彩音在中高声部；吉他上行琶音不和贝斯撞 |

## 曲式

```
Intro 4 小节 → Verse 16 → Pre 8 → Chorus 16 → Bridge 8 → Chorus 16 → Outro 4
```

## 声部

1. **电钢** — 柱式和弦，5 音内声位  
2. **贝斯** — 根音，句间留白  
3. **尼龙吉他** — 中高音区 8 分琶音（右偏）  
4. **Pad** — 每和弦 1–2 个高位长音（左/右散开）  
5. **主旋律** — 电钢音色，略偏中；微时间人性化  
6. **鼓** — Intro 无 → Verse 轻 → Pre 加 hat → Chorus 满 → Bridge 再轻 → 末副歌满
