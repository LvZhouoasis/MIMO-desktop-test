## 二、你要做的安装（约 15–30 分钟）

1. 官网下载 **ACE Studio**  
   - 搜索「ACE Studio 时域」或 `ace-studio.timedomain.cn`  
   - Windows 版安装包，按默认路径装
2. 打开后用手机号/微信登录（免费档一般够导出个人作品）
3. 确认自带 **中文 AI 歌手**（如「ACE 内置中文声库」）  
   - 若提示要下载声库：只下 1 个中文女声或男声即可（男声更贴方大同气质时选偏柔和的）
4. 不需要单独买 Vocaloid，除非你已有

**费用**：个人使用通常免费功能就够；商用/更高音质导出看软件内说明。先免费试完整流程。

## 四、ACE Studio 操作步骤

### 1. 导入 MIDI
1. 新建工程，速度确认 **72 BPM**
2. **文件 → 导入 MIDI**（或拖入）选择 `草稿箱_主旋律.mid`
3. 若弹出「导入音轨」，选 **主旋律音轨**，量化可关或弱量化

### 2. 贴歌词
1. 选中旋律轨 → 打开 **歌词 / Lyrics** 面板
2. 打开 `草稿箱_歌词对位.txt`，复制「可直接贴 ACE 歌词框」那一行  
   （空格分隔的整段）
3. 粘贴到歌词框，**按音符顺序对齐**  
   - ACE 多数版本支持「歌词批量粘贴到所选音符」
   - 若对不齐：用「逐音输入」，或按 8 个字一组从 txt 里往下贴
4. 中文一字一音即可；长音已在 MIDI 里写好时值

### 3. 选歌手与情绪
1. 轨上选 **中文 AI 男声**（偏气声/柔和）
2. 情绪/力度：主歌偏低、副歌略高（ACE 有 velocity / expression 可拉）
3. 不要开很强的自动修音到「机器人味」，保留一点自然

### 4. 导出人声
1. **导出 → 导出人声（干声 WAV）**  
   - 范围选 **整曲** 或与伴奏等长
2. 若只能导「人声+伴奏」：请把 ACE 里伴奏静音/不写和弦轨，只要人声

### 5. 与我的伴奏合（两种都行）

**A. 在 ACE 里合**  
导入 `草稿箱_跟唱伴奏.wav` 作音频轨 → 对齐开头 → 总导出

**B. 在剪映/Audacity 合（更稳）**  
1. 轨1：`草稿箱_跟唱伴奏.wav`  
2. 轨2：ACE 导出的人声  
3. 对齐第 1 拍（都在 72BPM，应能对上）  
4. 人声：轻混响 0.8–1.2s，音量略低于伴奏 1–2dB  
5. 导出 MP3

## 五、对不齐时

| 问题 | 处理 |
|------|------|
| 人声比伴奏快/慢 | 整体移动人声轨；或工程改 BPM 为 72 后重导 |
| 音高和伴奏打架 | 我 MIDI 已按 Ab 主旋律写；若 ACE 自动转调，关掉「自动适配调性」 |
| 某句字多挤 | 看 `歌词对位.txt` 逐句，把该句时值在 ACE 里拉长 |
| 想听「应长什么样」 | 对照 `草稿箱_导唱版.wav` |
