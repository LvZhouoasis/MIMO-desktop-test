# 《草稿箱》备选生成方案（不用 Suno）

Suno 登录失败时，按下面顺序试。词与曲风已为国内工具改写，**直接复制粘贴即可**。

---

## 方案 A：海绵音乐（推荐首选，字节）

- 入口：App Store / 应用商店搜「**海绵音乐**」，或浏览器搜「海绵音乐 AI 创作」
- 登录：一般用**抖音 / 手机号**，比 Suno 好过
- 模式：选 **「AI 写歌 / 自定义」**，把词贴进歌词框
- 免费：通常有每日生成次数，够你试几版

**风格框（可粘贴）：**
```
中文流行 R&B 抒情，方大同气质，慢板 72BPM，男声慵懒气声，温暖电钢与木吉他，夜色感，克制深情，不苦情嘶吼
```

**歌词框：** 见文末「统一歌词」

---

## 方案 B：网易天音 / 网易云音乐 AI 助手

- 入口：网易云音乐 App 内搜「AI 创作」「天音」，或天音网页
- 登录：**网易账号**即可
- 适合：中文咬字通常更稳

**风格 / 简介：**
```
Neo-Soul 中文抒情男声，类似方大同，72BPM，电钢+木吉他，主歌轻唱副歌略开
```

---

## 方案 C：天工 SkyMusic（昆仑万维）

- 入口：搜「天工音乐」「SkyMusic」
- 登录：手机号
- 特点：中文歌生成较直接，支持自定义歌词

**风格：**
```
华语 R&B 抒情，男声，夜色，电钢与吉他，慢歌，深情但克制
```

## 时长怎么到 3 分钟+

| 工具 | 做法 |
|------|------|
| 海绵音乐 | 生成后若偏短，用「继续写 / 加长」或把副歌复制成两遍再生成 |
| 网易天音 | 歌词尽量贴全（上面已是长结构）；有「段落重复」就多勾副歌 |
| 通用技巧 | 风格里写「**3分半到4分钟完整歌曲**」；副歌出现两次以上 |

**完整再生成一次时，把「尾声」整段保留**，不要删。
